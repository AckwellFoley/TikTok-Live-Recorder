# Changelog

## 1.0.0

- First public Windows desktop release of this fork.
- Portable app with a one-time, checksum-verified video engine download.
- Creator monitoring, independent recording workers and a concurrency queue.
- Separate comments, original feed and square guest-grid columns.
- Stable guest ordering and best-effort per-participant speaker highlights.
- Conservative mid-session speaker identity recovery with visible coverage.
- Local TikTok login import and TikTok-only Chrome export extension.
- Public source, dependency locks, license notices and release security evidence.

Based on upstream tiktok-live-recorder 7.7.1 by Michele0303.
